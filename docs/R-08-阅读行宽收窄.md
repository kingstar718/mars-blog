## 范围与验收

按用户确认的方案，将桌面页面最大宽度由 48rem 调整为 42rem，左右各 16px 内边距后正文约 640px。首页、文章、随记、标题栏和页脚统一对齐，保留现有字号、行高、手机边距与交互。不提交或部署。

- **AC-1**：全站布局共用 42rem 最大宽度，小屏保留全宽与左右各 16px 内边距；文章标题、正文、编辑区和评论对齐。
- **AC-2**：桌面目录定位由统一布局宽度推导，随正文收窄向内移动，保持 1.5rem 间隔和现有显示断点。
- **AC-3**：代码块保留横向滚动，宽表格可在自身横向滚动，不撑宽页面；保留现有阅读字号及行高。
- **AC-4**：首页、文章和随记 HTTP 200，输出新宽度与目录定位；相关文件格式检查通过。

## 决策与影响

- 最大宽度用共享 CSS 变量定义，供布局与目录定位共同使用，避免两处独立维护数值。
- 宽表格在正文中自身滚动，避免收窄后长表格越出阅读列。
- 影响范围为全站布局、文章目录、正文表格及说明文档，无数据、接口或依赖变更。
- 待确认项：无。
