## 范围与验收

按用户选择，通过 fonts.font.im 加载 Noto Serif SC 和 Noto Serif，参考 Paper 的中文、英文及数字排版。保留页面宽度和交互，代码继续使用等宽字体及横向滚动。此项为固定字体接入，不开放 R-02 的任意远端字体配置。

- **AC-1**：全站公共布局引入 Noto Serif SC 的 400、500、600、700 字重及 Noto Serif 的常规和斜体 400、500、600、700 字重，以及 Noto Sans Mono 的 400、500 字重，CSS 与字体请求使用 font.im 镜像域名。
- **AC-2**：全站字体 token 优先使用 Noto Serif，汉字回退 Noto Serif SC；加载失败时回退至本机宋体及通用 serif。采用 `display=swap`，不隐藏正文。
- **AC-3**：中文阅读正文采用 17/18px、500 字重、1.9 行高，标题与加粗采用 700；纯英文正文采用 400、1.7 行高、左对齐，中文强调使用着重号，英文强调使用斜体。日期和统计数字使用 Noto Serif、等宽数字且不自动添加字符间距。代码块和行内代码优先使用 Noto Sans Mono，中文和加载失败时回退本机等宽字体，保留字号、语法高亮与横向滚动。
- 标题栏和桌面、移动端目录显式使用全站衬线字体栈；站名 600、中文导航和目录 500、英文目录 400，目录的语言与正文对应。
- **AC-5**：构建期自动为纯英文 Markdown 段落、标题、列表项等设置 `lang="en"`，保留作者显式语言设置，不修改代码、原文或 R2；示例涵盖英文和数字。
- **AC-4**：文章和随记预览返回 HTTP 200，包含字体 stylesheet；相关文件格式检查和 Astro 类型检查通过。
- **AC-6**：生产 CSP 的 `style-src` 精确允许 `https://fonts.font.im`，`font-src` 精确允许 `https://fonts.gstatic.font.im`，保留其他现有来源限制，避免部署后拦截字体。

## 决策与影响

- 使用已验证的 Google Fonts 镜像，加上 CSS 域名及字体资源域名的 preconnect。
- 用西文字体优先的字体栈处理英文和数字，汉字自动回退 Noto Serif SC；纯英文段落在构建期标记语言，不增加运行时检测脚本。中文采用两端对齐，代码和英文保留左对齐。
- 影响范围：公共布局、字体 token、排版 CSS、构建期语言标记插件、CSP 字体域名许可、示例内容与说明文档。无新 npm 依赖、接口、数据库、R2 写入或部署操作；读者浏览器新增对第三方字体 CDN 的请求。
- CDN 在当前环境中已验证，国内不同运营商速度尚未验证；视觉效果通过本地文章及随记预览确认。
- 待确认项：无；接入方式已获用户授权。
