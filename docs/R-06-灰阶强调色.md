- 状态：待回归

- 登记：[需求索引](project.md)（R-06）

## 范围与验收

将全站绿色界面强调色改为接近日期文字的暖灰阶，沿用纸感背景、字体、布局及交互。代码语法高亮和示例图片保留原色彩，不改变内容。

- **AC-1**：浅色强调色使用日期所在的次要文字灰阶 `#5f5a52`，暗色使用 `#a9a49a`；导航、链接交互、目录、时间轴和编辑操作统一继承 token。
- **AC-2**：界面不再使用绿色强调；代码差异新增行的绿色背景和标记也改为灰阶，保留 `+` 标记以表达新增。
- **AC-3**：强调文字与页面背景、文本选区的前景与背景在两种主题中均达到 4.5:1；保留焦点轮廓、下划线和状态标记。
- **AC-4**：相关文件格式检查通过，本地首页、文章及随记 HTTP 200，并输出更新后的配色。
- **AC-5**：引用竖线为 1px，使用浅边框灰；正文、文章列表及 404 页的链接虚线为 1px，使用日期弱化灰。仅弱化装饰线，保留文字颜色及键盘焦点轮廓。

## 决策与影响

- 使用已有次要文字 token 对应的暖灰，不使用更浅的日期弱化色作为交互文字，避免降低可读性。
- 修改主题 token 与代码差异新增行样式；无依赖、接口或数据变更，不提交或部署。
- 待确认项：无。
